# Apple Watch Companion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone watchOS app that starts, stops and restarts stints from the wrist, shows the running stint as a complication, and syncs through CloudKit as a third peer.

**Architecture:** The watch reuses `TimeCore` unchanged in its rules: own SQLite file, same `SyncEngine` and `CloudKitTransport`. The assigned-issue list reaches it as one synced row (`assignedIssues`, R18) written by the Mac and the phone after every issue sync and read by the watch into its local issue cache. A WidgetKit extension renders the complication from an App Group store the watch app updates after every write and sync.

**Tech Stack:** Swift 5, SwiftUI, GRDB 7, CloudKit, WidgetKit, WatchKit (background refresh), XcodeGen 2.46, watchOS 10.

**Spec:** `docs/specs/2026-10-15-watch-design.md` (adds R17–R19 to `docs/specs/2026-10-14-sync-design.md`).

## Global Constraints

- App, Mobile, Watch and WatchWidget targets never import GRDB; all database access goes through `TimeCore`.
- `TimeCore` builds for macOS 14, iOS 17 and watchOS 10; the PDF files stay inside `#if os(macOS)`.
- The watch never imports or compiles `Shared/KeychainStore.swift` and never calls GitHub.
- Snapshot row uuid is exactly `00000000-0000-0000-0000-00000000a551`; record type `AssignedIssues`; table `assignedIssues`.
- Bundle ids: watch app `io.artnim.stint.ios.watchkitapp`, widget `io.artnim.stint.ios.watchkitapp.widget`; App Group `group.io.artnim.stint`; CloudKit container `iCloud.io.artnim.stint`, zone `stint`, environment Production on the watch.
- `MARKETING_VERSION` becomes `0.3.0` on every target in the last task; no tag, no push of tags, no `gh secret` from this plan.
- No secrets in the repo. The parity gate (reporting code) is untouched.
- Existing TimeCore tests (147, 1 skipped) keep passing; each task adds its own.
- Nothing in this plan can be verified against a live CloudKit container or a real watch on the implementing machine; those checks are listed for the user at the end.

## Review Focus

1. A stint started on the watch while the Mac runs one must converge on the later start everywhere, with the earlier one booked up to it (R7 across three peers). Test: `testThreePeersConvergeOnLaterStart` in Task 1.
2. The snapshot can arrive before the repo it names (the repo row came in a later batch, or the watch pruned nothing but never had the repo). The issue must appear once the repo exists, without a new snapshot. Test: `testReaderPicksUpRepoThatArrivesLater` in Task 1, and the watch runs the reader after every sync (Task 2).
3. A malformed or truncated payload must leave the wrist's list as it was, not empty. Test: `testMalformedPayloadLeavesCacheUntouched` in Task 1.
4. Pruning to one month must never remove the running stint or rows still waiting to upload. Test: `testOneMonthWindowKeepsRunningAndPending` in Task 1.
5. On the first day of a month the watch has pruned last month's entries, so "Recent" is empty until something is started from an issue or on another device. This follows from R17 as approved; the plan does not change it, but it is called out here for the user to decide later (keeping two months is a one-line change in `WatchState`).

```swift
    func testOneMonthWindowKeepsRunningAndPending() throws {
        let db = try AppDatabase.inMemory()
        let cal = Calendar(identifier: .gregorian)
        let now = cal.date(from: DateComponents(year: 2026, month: 10, day: 15, hour: 12))!
        let lastMonth = cal.date(from: DateComponents(year: 2026, month: 9, day: 3, hour: 9))!
        try db.start(description: "september", projectId: nil, at: lastMonth)
        _ = try db.stopRunning(at: lastMonth.addingTimeInterval(3600))
        try db.start(description: "pending september", projectId: nil, at: lastMonth.addingTimeInterval(7200))
        _ = try db.stopRunning(at: lastMonth.addingTimeInterval(9000))
        try db.start(description: "october", projectId: nil, at: now.addingTimeInterval(-3600))
        _ = try db.stopRunning(at: now.addingTimeInterval(-1800))
        try db.start(description: "running since september", projectId: nil, at: lastMonth.addingTimeInterval(20000))
        // everything except "pending september" has been pushed
        try db.write { try $0.execute(sql: "DELETE FROM outbox WHERE uuid != (SELECT uuid FROM entry WHERE description = 'pending september')") }
        let cutoff = windowStart(now: now, months: 1, calendar: cal)
        XCTAssertEqual(cutoff, cal.date(from: DateComponents(year: 2026, month: 10, day: 1))!)
        XCTAssertEqual(try db.pruneEntries(startingBefore: cutoff), 1)
        let left = try db.entries(from: lastMonth, to: now.addingTimeInterval(86400)).map(\.description).sorted()
        XCTAssertEqual(left, ["october", "pending september", "running since september"])
    }
```

```swift
/// R18: the assigned-issue snapshot for the watch. One row per database, fixed uuid, written by the
/// Mac and the phone after every issue sync, read by the watch. `payload` is JSON of [AssignedIssueItem].
public struct AssignedIssues: Codable, Identifiable, Equatable, SyncableRecord {
    public static let databaseTableName = "assignedIssues"
    public static let fixedUUID = "00000000-0000-0000-0000-00000000a551"
    public var id: Int64?
    public var fetchedAt: Date
    public var payload: String
    public var uuid: String
    public var modifiedAt: Date
    public var modifiedBy: String
    public var deletedAt: Date?

    public init(id: Int64? = nil, uuid: String = AssignedIssues.fixedUUID, fetchedAt: Date, payload: String,
                modifiedAt: Date = Date(), modifiedBy: String = "", deletedAt: Date? = nil) {
        self.id = id; self.uuid = uuid; self.fetchedAt = fetchedAt; self.payload = payload
        self.modifiedAt = modifiedAt; self.modifiedBy = modifiedBy; self.deletedAt = deletedAt
    }
    public mutating func didInsert(_ inserted: InsertionSuccess) { id = inserted.rowID }
}

public struct AssignedIssueItem: Codable, Equatable {
    public var repo: String       // owner/name
    public var number: Int
    public var title: String
    public var project: String?   // project uuid
    public init(repo: String, number: Int, title: String, project: String?) {
        self.repo = repo; self.number = number; self.title = title; self.project = project
    }
}
```

```swift
import Foundation
import GRDB

extension AppDatabase {
    /// R18 writer: the open issues assigned to me, ordered by repo then number, as one synced row.
    public func writeAssignedIssueSnapshot(now: Date = Date()) throws {
        try write { db in
            let repos = Dictionary(uniqueKeysWithValues: try Repo.filter(Column("deletedAt") == nil).fetchAll(db).map { ($0.id!, $0) })
            let projects = Dictionary(uniqueKeysWithValues: try Project.filter(Column("deletedAt") == nil).fetchAll(db).map { ($0.id!, $0.uuid) })
            let items = try IssueCache.filter(Column("state") == "open" && Column("assignedToMe") == true).fetchAll(db)
                .compactMap { i -> AssignedIssueItem? in
                    guard let repo = repos[i.repoId] else { return nil }
                    return AssignedIssueItem(repo: repo.fullName, number: i.number, title: i.title,
                                             project: repo.projectId.flatMap { projects[$0] })
                }
                .sorted { ($0.repo, $0.number) < ($1.repo, $1.number) }
            let encoder = JSONEncoder()
            encoder.outputFormatting = [.sortedKeys]
            let payload = String(decoding: try encoder.encode(items), as: UTF8.self)
            if var row: AssignedIssues = try db.fetchByUUID(uuid: AssignedIssues.fixedUUID) {
                row.fetchedAt = now; row.payload = payload; row.deletedAt = nil
                try db.syncUpdate(&row, deviceId: deviceId, now: now)
            } else {
                var row = AssignedIssues(fetchedAt: now, payload: payload)
                try db.syncInsert(&row, deviceId: deviceId, now: now)
            }
        }
    }

    /// R18 reader (watch only): replaces the issue cache with the snapshot. Repos are resolved by full name;
    /// an unknown repo skips its issues until the repo arrives. Returns the number of cached issues, or -1
    /// when there is no row or the payload does not parse (the cache is then left untouched).
    @discardableResult
    public func applyAssignedIssueSnapshot() throws -> Int {
        try write { db in
            guard let row: AssignedIssues = try db.fetchByUUID(uuid: AssignedIssues.fixedUUID),
                  let items = try? JSONDecoder().decode([AssignedIssueItem].self, from: Data(row.payload.utf8)) else { return -1 }
            let repos = Dictionary(uniqueKeysWithValues: try Repo.filter(Column("deletedAt") == nil).fetchAll(db).map { ($0.fullName, $0.id!) })
            try db.execute(sql: "DELETE FROM issueCache")
            var count = 0
            for item in items {
                guard let repoId = repos[item.repo] else { continue }
                var cached = IssueCache(repoId: repoId, number: item.number, title: item.title,
                                        isPullRequest: false, state: "open", updatedAt: row.fetchedAt, assignedToMe: true)
                try cached.insert(db)
                count += 1
            }
            return count
        }
    }
}
```

```swift
import Foundation

/// What the complication shows, written by the watch app after every write and sync, read by the widget.
enum ComplicationStore {
    static let suite = "group.io.artnim.stint"
    private static let key = "complication"

    struct Snapshot: Codable, Equatable {
        var description: String?
        var start: Date?
        static let idle = Snapshot(description: nil, start: nil)
    }

    static func save(_ s: Snapshot) {
        guard let d = UserDefaults(suiteName: suite), let data = try? JSONEncoder().encode(s) else { return }
        d.set(data, forKey: key)
    }

    static func load() -> Snapshot {
        guard let d = UserDefaults(suiteName: suite), let data = d.data(forKey: key),
              let s = try? JSONDecoder().decode(Snapshot.self, from: data) else { return .idle }
        return s
    }
}
```

```swift
import Foundation
import Observation
import TimeCore
import WidgetKit

@Observable @MainActor
final class WatchState {
    static weak var shared: WatchState?   // read only from @MainActor tasks
    let db: AppDatabase
    var running: Entry?
    var lastFinished: Entry?
    var recents: [RecentItem] = []
    var projects: [Project] = []
    var issueRows: [IssueRow] = []
    var today: [Entry] = []
    var now = Date()
    var lastError: String?
    var syncStatus = "Sync: not started"
    private let transport: CloudKitTransport
    private let engine: SyncEngine

    static var databaseURL: URL {
        FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0].appending(path: "Stint/stint.sqlite")
    }

    init() {
        db = try! AppDatabase.open(at: Self.databaseURL)      // no alert path on the wrist; a failure here is a programming error
        transport = CloudKitTransport(database: db)
        engine = SyncEngine(database: db, transport: transport)
        Self.shared = self
        refresh()
        Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.now = Date() }
        }
        NotificationCenter.default.addObserver(forName: CloudKitTransport.accountChangedNotification, object: nil, queue: .main) { [weak self] _ in
            Task { @MainActor in await self?.syncNow(reason: "account changed") }
        }
    }

    func refresh() {
        do {
            running = try db.runningEntry()
            recents = try db.recents(limit: 10)
            projects = try db.allProjects()
            issueRows = try db.openIssueRows()
            let cal = Calendar.current
            let dayStart = cal.startOfDay(for: Date())
            today = try db.entries(from: dayStart, to: dayStart.addingTimeInterval(86400)).reversed()
            lastFinished = try db.finishedEntries(from: windowStart(now: Date(), months: 1, calendar: cal), to: Date().addingTimeInterval(86400)).last
            now = Date()
        } catch { lastError = "\(error)" }
        ComplicationStore.save(.init(description: running?.description, start: running?.startUTC))
        WidgetCenter.shared.reloadAllTimelines()
    }

    func projectName(_ id: Int64?) -> String { projects.first { $0.id == id }?.name ?? "" }

    func elapsed(_ e: Entry) -> String {
        let s = Int(max(0, now.timeIntervalSince(e.startUTC)))
        return String(format: "%d:%02d:%02d", s / 3600, (s % 3600) / 60, s % 60)
    }

    private func perform(_ reason: String, _ block: () throws -> Void) {
        do { try block(); lastError = nil } catch { lastError = "\(error)" }
        refresh()
        Task { await syncNow(reason: reason) }        // R19: a tap leaves the wrist at once
    }

    func start(_ item: RecentItem) {
        perform("start") { try db.start(description: item.description, projectId: item.projectId, repoId: item.repoId,
                                        issueNumber: item.issueNumber, issueTitle: item.issueTitle) }
    }
    func startIssue(_ row: IssueRow) {
        perform("start") { try db.start(description: "#\(row.issue.number): \(row.issue.title)", projectId: row.repo.projectId,
                                        repoId: row.repo.id, issueNumber: row.issue.number, issueTitle: row.issue.title) }
    }
    func restartLast() {
        guard let e = lastFinished else { return }
        perform("restart") { try db.start(description: e.description, projectId: e.projectId, repoId: e.repoId,
                                          issueNumber: e.issueNumber, issueTitle: e.issueTitle, tags: e.tags) }
    }
    func stop() { perform("stop") { try db.stopRunning() } }
    func delete(_ entry: Entry) { perform("delete") { try db.delete(entry) } }

    // MARK: sync

    func syncNow(reason: String) async {
        let available = await transport.accountAvailable()
        guard !Task.isCancelled else { return }
        guard available else { syncStatus = "Sync off: not signed in to iCloud"; return }
        do {
            // R11: a different iCloud account keeps the local data and stops syncing
            let user = try await transport.userRecordName()
            if let stored = try db.setting("syncUserRecordID"), !stored.isEmpty {
                guard stored == user else { syncStatus = "iCloud account changed, sync stopped"; return }
            } else {
                try db.setSetting("syncUserRecordID", user)
            }
            try await transport.prepare()
            let s = try await engine.sync()
            try db.pruneEntries(startingBefore: windowStart(now: Date(), months: 1, calendar: .current))   // R17
            try db.applyAssignedIssueSnapshot()                                                          // R18, after every cycle (Review Focus 2)
            refresh()
            let stamp = Date().formatted(date: .omitted, time: .shortened)
            syncStatus = "Synced \(stamp): \(s.pushed) up, \(s.pulled) down" + (s.failed > 0 ? ", \(s.failed) failed" : "")
        } catch {
            syncStatus = "Sync problem: \(error.localizedDescription)"
        }
    }
}
```

```swift
struct WatchStintView: View {
    @Environment(WatchState.self) private var state

    var body: some View {
        NavigationStack {
            List {
                if let r = state.running {
                    Section {
                        Text(r.description.isEmpty ? "—" : r.description).font(.headline).lineLimit(2)
                        Text(state.projectName(r.projectId)).font(.caption2).foregroundStyle(.secondary)
                        Text(r.startUTC, style: .timer).font(.title3).monospacedDigit()
                        Button("Stop", role: .destructive) { state.stop() }
                    }
                } else {
                    Section {
                        Text("Nothing running").foregroundStyle(.secondary)
                        if let last = state.lastFinished {
                            Button { state.restartLast() } label: {
                                VStack(alignment: .leading) {
                                    Text("Restart last").font(.headline)
                                    Text(last.description.isEmpty ? "—" : last.description).font(.caption2).lineLimit(1)
                                }
                            }
                        }
                    }
                }
                if !state.recents.isEmpty {
                    Section("Recent") {
                        ForEach(state.recents, id: \.self) { item in
                            Button { state.start(item) } label: {
                                VStack(alignment: .leading) {
                                    Text(item.description.isEmpty ? "—" : item.description).lineLimit(2)
                                    Text(state.projectName(item.projectId)).font(.caption2).foregroundStyle(.secondary)
                                }
                            }
                        }
                    }
                }
                ForEach(groups) { group in
                    Section(group.name ?? "Unmapped") {
                        ForEach(group.rows) { row in
                            Button { state.startIssue(row) } label: {
                                HStack(alignment: .top) {
                                    Text(verbatim: "#\(row.issue.number)").monospacedDigit().foregroundStyle(.secondary)
                                    Text(row.issue.title).lineLimit(2)
                                }
                            }
                        }
                    }
                }
                if let err = state.lastError { Text(err).font(.caption2).foregroundStyle(.red) }
            }
            .navigationTitle("Stint")
            .sensoryFeedback(.success, trigger: state.running?.uuid)
        }
    }

    private struct IssueGroup: Identifiable { let name: String?; let rows: [IssueRow]; var id: String { name ?? "\u{0}" } }
    private var groups: [IssueGroup] {
        var order: [String?] = []; var byName: [String?: [IssueRow]] = [:]
        for r in state.issueRows { if byName[r.projectName] == nil { order.append(r.projectName) }; byName[r.projectName, default: []].append(r) }
        return order.map { IssueGroup(name: $0, rows: byName[$0]!) }
    }
}
```

```swift
import SwiftUI
import WidgetKit

struct RunningEntry: TimelineEntry {
    let date: Date
    let description: String?
    let start: Date?
}

struct RunningProvider: TimelineProvider {
    func placeholder(in context: Context) -> RunningEntry { RunningEntry(date: Date(), description: "#1403: Login", start: Date().addingTimeInterval(-1500)) }
    func getSnapshot(in context: Context, completion: @escaping (RunningEntry) -> Void) { completion(current()) }
    func getTimeline(in context: Context, completion: @escaping (Timeline<RunningEntry>) -> Void) {
        completion(Timeline(entries: [current()], policy: .never))   // the app reloads the timeline on every change
    }
    private func current() -> RunningEntry {
        let s = ComplicationStore.load()
        return RunningEntry(date: Date(), description: s.description, start: s.start)
    }
}

struct RunningView: View {
    @Environment(\.widgetFamily) private var family
    let entry: RunningEntry

    var body: some View {
        switch family {
        case .accessoryRectangular:
            VStack(alignment: .leading, spacing: 2) {
                HStack(spacing: 4) { ring; Text("Stint").font(.caption2).foregroundStyle(.secondary) }
                if let start = entry.start {
                    Text(entry.description?.isEmpty == false ? entry.description! : "—").font(.headline).lineLimit(1)
                    Text(start, style: .timer).font(.title3).monospacedDigit()
                } else {
                    Text("—").font(.title3)
                }
            }
        case .accessoryInline:
            if let start = entry.start { Text("Stint · \(start, style: .timer)") } else { Text("Stint · —") }
        default:   // .accessoryCircular
            VStack(spacing: 0) {
                ring
                if let start = entry.start { Text(start, style: .timer).font(.caption2).monospacedDigit().minimumScaleFactor(0.6) }
                else { Text("—").font(.caption2) }
            }
        }
    }

    private var ring: some View {
        Image("MenuBarIcon").renderingMode(.template).resizable().scaledToFit().frame(width: 14, height: 14)
    }
}

@main
struct StintWatchWidget: Widget {
    var body: some WidgetConfiguration {
        StaticConfiguration(kind: "io.artnim.stint.running", provider: RunningProvider()) { entry in
            RunningView(entry: entry).containerBackground(.clear, for: .widget)
        }
        .configurationDisplayName("Running stint")
        .description("What is running and for how long.")
        .supportedFamilies([.accessoryRectangular, .accessoryCircular, .accessoryInline])
    }
}
```

```swift
import SwiftUI
import TimeCore
import WatchKit

final class WatchDelegate: NSObject, WKApplicationDelegate {
    func applicationDidFinishLaunching() { Self.scheduleRefresh() }

    func handle(_ backgroundTasks: Set<WKRefreshBackgroundTask>) {
        for task in backgroundTasks {
            guard let refresh = task as? WKApplicationRefreshBackgroundTask else { task.setTaskCompletedWithSnapshot(false); continue }
            Task { @MainActor in
                await WatchState.shared?.syncNow(reason: "background refresh")   // pulls, prunes (R17), applies the snapshot (R18), refreshes the complication
                Self.scheduleRefresh()
                refresh.setTaskCompletedWithSnapshot(false)
            }
        }
    }

    /// R19: about every 30 minutes while the watch is worn; watchOS decides the exact moment.
    static func scheduleRefresh() {
        WKApplication.shared().scheduleBackgroundRefresh(withPreferredDate: Date().addingTimeInterval(30 * 60), userInfo: nil) { _ in }
    }
}

@main
struct WatchApp: App {
    @WKApplicationDelegateAdaptor(WatchDelegate.self) private var delegate
    @State private var state = WatchState()
    @Environment(\.scenePhase) private var scenePhase

    var body: some Scene {
        WindowGroup {
            TabView {
                WatchStintView()
                WatchTodayView()
                WatchSettingsView()
            }
            .tabViewStyle(.verticalPage)
            .environment(state)
        }
        .onChange(of: scenePhase) { _, phase in
            if phase == .active { Task { await state.syncNow(reason: "foreground") } }
            if phase == .background { WatchDelegate.scheduleRefresh() }
        }
    }
}
```
