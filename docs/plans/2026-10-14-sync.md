# Sync and iPhone Companion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stint's Mac and a new iPhone app converge on the same data through the user's private CloudKit database, with a sync engine in TimeCore that follows the fifteen rules in the spec.

**Architecture:** Every synced row gets a uuid, a modification stamp and a tombstone; every local write logs itself into an outbox in the same transaction. A `SyncEngine` actor runs pull → apply (last-writer-wins per row, deletions win) → push against a `SyncTransport`; an in-memory server implements the transport for tests, `CloudKitTransport` for production. The Mac app gains triggers and a status line; a SwiftUI iOS target shares TimeCore and a `Shared/` folder for the Keychain code.

**Tech Stack:** Swift 5 mode, GRDB 7, CloudKit, SwiftUI (macOS 14, iOS 17), XcodeGen, XCTest.

**Spec:** `docs/specs/2026-10-14-sync-design.md`. The rule numbers (R1–R15) below refer to it.

## Global Constraints

- Only third-party dependency stays GRDB. CloudKit is used directly, no wrapper library.
- camelCase tables and columns; new columns `uuid`, `modifiedAt`, `modifiedBy`, `deletedAt`; new table `outbox`.
- Synced tables: `client`, `project`, `repo`, `entry`; synced settings keys: `userName`, `reportPresets`. Never synced: `issueCache`, settings `databasePath`, `syncZoneToken`, `deviceId`.
- R3: last-writer-wins per whole row by `modifiedAt`, tie-break by `modifiedBy` (the device id) string order. R4: deletions win.
- R5: every local write of a synced row logs `(tableName, uuid, op)` into `outbox` in the same transaction. R6: pull, apply, push, then store the token. R9: applying a batch is idempotent; the token is stored in the apply transaction.
- R7: after apply, at most one running entry; the latest start wins, others end at `max(theirStart, keeperStart)`.
- R14: the phone prunes finished entries starting before the first day of the month two months back, bypassing the outbox. R15: month total = raw finished hours in the current month + running elapsed, unrounded.
- CloudKit: container `iCloud.io.artnim.stint`, custom zone `stint`, record types `Client`, `Project`, `Repo`, `Entry`, `Setting`, `recordName` = uuid (settings: the key), references as uuid strings, save policy "all keys" (blind overwrite; LWW is decided by the stamps, not by the server).
- Remote-applied rows are written without touching the outbox; only local user actions and R7 resolutions log.
- The app targets never import GRDB or CloudKit; all of it lives in TimeCore.
- Commit after every task on `main`, as before.

## Review Focus

1. **Edit after delete on the other device** (R4 both directions): an entry deleted on the phone while edited on the Mac must end up deleted on both, never resurrected. Tests in Task 3.
2. **Two stints started offline** (R7): both devices running, one started 10:00, one 10:30; after sync exactly one runs and the other is booked 10:00–10:30. Tests in Task 4.
3. **Crash between write and push** (R5, R9): rows written but not pushed survive a restart; a batch replayed after a crash changes nothing. Tests in Tasks 1 and 3.
4. **Pruning must never delete the Mac's history** (R14): a prune on the phone creates no outbox rows and no CloudKit deletions. Tests in Task 5.
5. **A device without iCloud, or offline for a day**: local use continues, the outbox grows, and the first successful cycle pushes everything in order. Tests in Task 3 (failing transport) and the status handling in Task 6.

```swift
import Foundation
import GRDB

public protocol SyncableRecord: FetchableRecord, MutablePersistableRecord {
    static var databaseTableName: String { get }
    var id: Int64? { get }
    var uuid: String { get set }
    var modifiedAt: Date { get set }
    var modifiedBy: String { get set }
    var deletedAt: Date? { get set }
}

public enum SyncOp: String, Codable { case upsert, delete }

public enum SyncTables {
    public static let synced = ["client", "project", "repo", "entry"]
    public static let syncedSettings: Set<String> = ["userName", "reportPresets"]
}

/// One pending change (R5). Drained by the sync engine after the server acknowledges it.
public struct OutboxItem: Codable, Identifiable, Equatable, FetchableRecord, MutablePersistableRecord {
    public static let databaseTableName = "outbox"
    public var id: Int64?
    public var tableName: String
    public var uuid: String
    public var op: String
    public var createdAt: Date
    public mutating func didInsert(_ inserted: InsertionSuccess) { id = inserted.rowID }
}

extension Database {
    public func logChange(table: String, uuid: String, op: SyncOp, now: Date) throws {
        var item = OutboxItem(tableName: table, uuid: uuid, op: op.rawValue, createdAt: now)
        try item.insert(self)
    }

    public func fetchByUUID<T: SyncableRecord>(uuid: String) throws -> T? {
        try T.filter(Column("uuid") == uuid).fetchOne(self)
    }

    public func syncInsert<T: SyncableRecord>(_ r: inout T, deviceId: String, now: Date) throws {
        r.modifiedAt = now; r.modifiedBy = deviceId; r.deletedAt = nil
        try r.insert(self)
        try logChange(table: T.databaseTableName, uuid: r.uuid, op: .upsert, now: now)
    }

    public func syncUpdate<T: SyncableRecord>(_ r: inout T, deviceId: String, now: Date) throws {
        r.modifiedAt = now; r.modifiedBy = deviceId
        try r.update(self)
        try logChange(table: T.databaseTableName, uuid: r.uuid, op: .upsert, now: now)
    }

    /// R4: a local delete becomes a tombstone until the deletion is pushed.
    public func syncTombstone<T: SyncableRecord>(_ r: inout T, deviceId: String, now: Date) throws {
        r.modifiedAt = now; r.modifiedBy = deviceId; r.deletedAt = now
        try r.update(self)
        try logChange(table: T.databaseTableName, uuid: r.uuid, op: .delete, now: now)
    }
}
```

```swift
    /// Plain records (issueCache, outbox): no stamps, no log.
    public func insert<T: MutablePersistableRecord>(_ record: inout T) throws { try write { try record.insert($0) } }
    public func update<T: MutablePersistableRecord>(_ record: T) throws { try write { try record.update($0) } }
    public func delete<T: MutablePersistableRecord>(_ record: T) throws { try write { _ = try record.delete($0) } }

    public func insert<T: SyncableRecord>(_ record: inout T) throws {

        try write { try $0.syncInsert(&r, deviceId: deviceId, now: Date()) }
        record = r

    public func update<T: SyncableRecord>(_ record: T) throws {
        var r = record
        try write { try $0.syncUpdate(&r, deviceId: deviceId, now: Date()) }
```

```swift
import Foundation

public enum SyncValue: Equatable, Codable, Sendable {
    case string(String), int(Int64), double(Double), bool(Bool), date(Date), strings([String]), null
}

public struct SyncRecordID: Hashable, Codable, Sendable {
    public var type: String
    public var name: String
    public init(type: String, name: String) { self.type = type; self.name = name }
}

/// Transport-neutral record: what CloudKit stores, what the in-memory server stores.
public struct SyncRecord: Equatable, Codable, Sendable {
    public var type: String
    public var name: String
    public var fields: [String: SyncValue]

    public init(type: String, name: String, fields: [String: SyncValue]) {
        self.type = type; self.name = name; self.fields = fields
    }
    public var id: SyncRecordID { SyncRecordID(type: type, name: name) }

    public func string(_ k: String) -> String? { if case .string(let v)? = fields[k] { return v }; return nil }
    public func int(_ k: String) -> Int64? { if case .int(let v)? = fields[k] { return v }; return nil }
    public func double(_ k: String) -> Double? { if case .double(let v)? = fields[k] { return v }; return nil }
    public func bool(_ k: String) -> Bool? { if case .bool(let v)? = fields[k] { return v }; return nil }
    public func date(_ k: String) -> Date? { if case .date(let v)? = fields[k] { return v }; return nil }
    public func strings(_ k: String) -> [String]? { if case .strings(let v)? = fields[k] { return v }; return nil }
}

public struct SyncChanges: Equatable, Sendable {
    public var changed: [SyncRecord]
    public var deleted: [SyncRecordID]
    public var token: String?
    public init(changed: [SyncRecord], deleted: [SyncRecordID], token: String?) {
        self.changed = changed; self.deleted = deleted; self.token = token
    }
}

public enum SyncSaveOutcome: Equatable, Sendable { case saved, notFound, failed(String) }

/// What the engine needs from a server. Saves are blind overwrites; LWW is decided by stamps.
public protocol SyncTransport: Sendable {
    func fetchChanges(since token: String?) async throws -> SyncChanges
    func save(_ records: [SyncRecord]) async throws -> [SyncRecordID: SyncSaveOutcome]
    func delete(_ ids: [SyncRecordID]) async throws
}
```

```swift
import Foundation

/// A fake server shared by the "devices" in tests: a record store plus a change log with
/// sequence numbers; the token is the last sequence number a client has seen.
public actor InMemorySyncServer: SyncTransport {
    public struct Failure: Error {}
    private var store: [SyncRecordID: SyncRecord] = [:]
    private var log: [(seq: Int, id: SyncRecordID, deleted: Bool)] = []
    private var seq = 0
    private var failNext = false

    public init() {}

    public func setFailNext(_ v: Bool) { failNext = v }
    public func records() -> [SyncRecordID: SyncRecord] { store }

    private func checkFailure() throws {
        if failNext { failNext = false; throw Failure() }
    }

    public func fetchChanges(since token: String?) async throws -> SyncChanges {
        try checkFailure()
        let after = token.flatMap(Int.init) ?? 0
        var latest: [SyncRecordID: Bool] = [:]      // id -> deleted?
        var order: [SyncRecordID] = []
        for e in log where e.seq > after {
            if latest[e.id] == nil { order.append(e.id) }
            latest[e.id] = e.deleted
        }
        let changed = order.compactMap { id -> SyncRecord? in latest[id] == false ? store[id] : nil }
        let deleted = order.filter { latest[$0] == true }
        return SyncChanges(changed: changed, deleted: deleted, token: String(seq))
    }

    public func save(_ records: [SyncRecord]) async throws -> [SyncRecordID: SyncSaveOutcome] {
        try checkFailure()
        var out: [SyncRecordID: SyncSaveOutcome] = [:]
        for r in records {
            seq += 1
            store[r.id] = r
            log.append((seq, r.id, false))
            out[r.id] = .saved
        }
        return out
    }

    public func delete(_ ids: [SyncRecordID]) async throws {
        try checkFailure()
        for id in ids where store[id] != nil {
            seq += 1
            store[id] = nil
            log.append((seq, id, true))
        }
    }
}
```

```swift
import Foundation

/// Rows <-> transport records. References travel as uuid strings; resolving them to local
/// ids is the engine's job, so `apply` never touches `projectId`/`clientId`/`repoId`.
enum RecordMapper {
    static let types = ["Client", "Project", "Repo", "Entry", "Setting"]

    static func table(forType type: String) -> String? {
        switch type {
        case "Client": return "client"
        case "Project": return "project"
        case "Repo": return "repo"
        case "Entry": return "entry"
        case "Setting": return "setting"
        default: return nil
        }
    }

    private static func stamps(_ modifiedAt: Date, _ modifiedBy: String) -> [String: SyncValue] {
        ["modifiedAt": .date(modifiedAt), "modifiedBy": .string(modifiedBy)]
    }
    private static func opt(_ s: String?) -> SyncValue { s.map { .string($0) } ?? .null }

    static func record(client c: Client) -> SyncRecord {
        SyncRecord(type: "Client", name: c.uuid, fields: stamps(c.modifiedAt, c.modifiedBy).merging(
            ["name": .string(c.name), "archived": .bool(c.archived)]) { $1 })
    }

    static func record(project p: Project, clientUUID: String?) -> SyncRecord {
        SyncRecord(type: "Project", name: p.uuid, fields: stamps(p.modifiedAt, p.modifiedBy).merging(
            ["name": .string(p.name), "archived": .bool(p.archived), "clientUUID": opt(clientUUID)]) { $1 })
    }

    static func record(repo r: Repo, projectUUID: String?) -> SyncRecord {
        SyncRecord(type: "Repo", name: r.uuid, fields: stamps(r.modifiedAt, r.modifiedBy).merging(
            ["owner": .string(r.owner), "name": .string(r.name), "projectUUID": opt(projectUUID)]) { $1 })
    }

    static func record(entry e: Entry, projectUUID: String?, repoUUID: String?) -> SyncRecord {
        SyncRecord(type: "Entry", name: e.uuid, fields: stamps(e.modifiedAt, e.modifiedBy).merging([
            "startUTC": .date(e.startUTC),
            "endUTC": e.endUTC.map { .date($0) } ?? .null,
            "description": .string(e.description),
            "issueNumber": e.issueNumber.map { .int(Int64($0)) } ?? .null,
            "issueTitle": opt(e.issueTitle),
            "tags": .strings(e.tags),
            "importedKey": opt(e.importedKey),
            "projectUUID": opt(projectUUID),
            "repoUUID": opt(repoUUID),
        ]) { $1 })
    }

    static func record(settingKey key: String, value: String, modifiedAt: Date, modifiedBy: String) -> SyncRecord {
        SyncRecord(type: "Setting", name: key, fields: stamps(modifiedAt, modifiedBy).merging(["value": .string(value)]) { $1 })
    }

    static func apply(_ r: SyncRecord, to c: inout Client) {
        c.name = r.string("name") ?? c.name
        c.archived = r.bool("archived") ?? c.archived
        applyStamps(r, &c.modifiedAt, &c.modifiedBy)
    }
    static func apply(_ r: SyncRecord, to p: inout Project) {
        p.name = r.string("name") ?? p.name
        p.archived = r.bool("archived") ?? p.archived
        applyStamps(r, &p.modifiedAt, &p.modifiedBy)
    }
    static func apply(_ r: SyncRecord, to x: inout Repo) {
        x.owner = r.string("owner") ?? x.owner
        x.name = r.string("name") ?? x.name
        applyStamps(r, &x.modifiedAt, &x.modifiedBy)
    }
    static func apply(_ r: SyncRecord, to e: inout Entry) {
        e.startUTC = r.date("startUTC") ?? e.startUTC
        e.endUTC = r.date("endUTC")                       // .null -> nil: a running stint
        e.description = r.string("description") ?? e.description
        e.issueNumber = r.int("issueNumber").map(Int.init)
        e.issueTitle = r.string("issueTitle")
        e.tags = r.strings("tags") ?? []
        e.importedKey = r.string("importedKey")
        applyStamps(r, &e.modifiedAt, &e.modifiedBy)
    }
    private static func applyStamps(_ r: SyncRecord, _ at: inout Date, _ by: inout String) {
        at = r.date("modifiedAt") ?? at
        by = r.string("modifiedBy") ?? by
    }
}
```

```swift
/// A "device": its own in-memory database and an engine talking to the shared fake server.
func makeDevice(_ server: InMemorySyncServer, now: @escaping @Sendable () -> Date = { Date() }) throws -> (db: AppDatabase, engine: SyncEngine) {
    let db = try AppDatabase.inMemory()
    return (db, SyncEngine(database: db, transport: server, now: now))
}

/// Writes a synced row with an explicit stamp, the way a user edit on that device at that time would.
func edit<T: SyncableRecord>(_ db: AppDatabase, _ row: inout T, at: Date, _ change: (inout T) -> Void) throws {
    change(&row)
    var r = row
    try db.write { try $0.syncUpdate(&r, deviceId: db.deviceId, now: at) }
    row = r
}

func tombstone<T: SyncableRecord>(_ db: AppDatabase, _ row: T, at: Date) throws {
    var r = row
    try db.write { try $0.syncTombstone(&r, deviceId: db.deviceId, now: at) }
}

/// Records which transport calls happened, in order.

    let inner: InMemorySyncServer

    func save(_ records: [SyncRecord]) async throws -> [SyncRecordID: SyncSaveOutcome] { calls.append("save"); return try await inner.save(records) }
    func delete(_ ids: [SyncRecordID]) async throws { calls.append("delete"); try await inner.delete(ids) }
```

```swift
import Foundation
import GRDB

public struct SyncSummary: Equatable, Sendable {
    public var pulled = 0
    public var deleted = 0
    public var pushed = 0
    public init(pulled: Int = 0, deleted: Int = 0, pushed: Int = 0) { self.pulled = pulled; self.deleted = deleted; self.pushed = pushed }
}

/// One cycle: pull remote changes since the stored token, apply them (R3, R4, R8, R9),
/// then push the outbox (R5). Never touches the outbox for remote-applied rows.
public actor SyncEngine {
    public static let tokenKey = "syncZoneToken"
    let db: AppDatabase
    let transport: any SyncTransport
    let now: @Sendable () -> Date

    public init(database: AppDatabase, transport: any SyncTransport, now: @escaping @Sendable () -> Date = { Date() }) {
        self.db = database; self.transport = transport; self.now = now
    }

    public func sync() async throws -> SyncSummary {
        var summary = SyncSummary()
        let token = try db.setting(Self.tokenKey)
        let changes = try await transport.fetchChanges(since: token)
        (summary.pulled, summary.deleted) = try apply(changes)
        summary.pushed = try await push()
        return summary
    }

    // MARK: pull

    public func apply(_ changes: SyncChanges) throws -> (pulled: Int, deleted: Int) {
        let deviceId = db.deviceId
        let now = self.now()
        return try db.write { db in
            var pulled = 0
            let byType = Dictionary(grouping: changes.changed, by: \.type)
            for type in RecordMapper.types {                      // R8: parents first
                for r in byType[type] ?? [] {
                    if try Self.applyRecord(r, in: db) { pulled += 1 }
                }
            }
            var deleted = 0
            for id in changes.deleted {
                guard let table = RecordMapper.table(forType: id.type) else { continue }
                if table == "setting" {
                    try db.execute(sql: "DELETE FROM setting WHERE key = ?", arguments: [id.name])
                } else {
                    try db.execute(sql: "DELETE FROM \(table) WHERE uuid = ?", arguments: [id.name])
                }
                try db.execute(sql: "DELETE FROM outbox WHERE tableName = ? AND uuid = ?", arguments: [table, id.name])
                deleted += 1
            }
            _ = deviceId   // used by Task 4's resolveRunningStints call, added there
            if let token = changes.token {
                try Setting(key: Self.tokenKey, value: token, modifiedAt: now, modifiedBy: deviceId).save(db)
            }
            return (pulled, deleted)
        }
    }

    static func localWins(_ lAt: Date, _ lBy: String, _ rAt: Date, _ rBy: String) -> Bool {
        lAt > rAt || (lAt == rAt && lBy > rBy)
    }

    /// Returns true when the local row changed.
    static func applyRecord(_ r: SyncRecord, in db: Database) throws -> Bool {
        switch r.type {
        case "Client":
            return try upsert(r, in: db, make: { Client(name: "", uuid: r.name) }) { c, _ in RecordMapper.apply(r, to: &c) }
        case "Project":
            return try upsert(r, in: db, make: { Project(clientId: nil, name: "", uuid: r.name) }) { p, db in
                RecordMapper.apply(r, to: &p)
                p.clientId = try resolve(Client.self, uuid: r.string("clientUUID"), in: db)
            }
        case "Repo":
            return try upsert(r, in: db, make: { Repo(owner: "", name: "", uuid: r.name) }) { x, db in
                RecordMapper.apply(r, to: &x)
                x.projectId = try resolve(Project.self, uuid: r.string("projectUUID"), in: db)
            }
        case "Entry":
            return try upsert(r, in: db, make: { Entry(description: "", startUTC: Date(), uuid: r.name) }) { e, db in
                RecordMapper.apply(r, to: &e)
                e.projectId = try resolve(Project.self, uuid: r.string("projectUUID"), in: db)
                e.repoId = try resolve(Repo.self, uuid: r.string("repoUUID"), in: db)
            }
        case "Setting":
            let remoteAt = r.date("modifiedAt") ?? .distantPast
            let remoteBy = r.string("modifiedBy") ?? ""
            if let local = try Setting.fetchOne(db, key: r.name) {
                if local.modifiedAt == remoteAt && local.modifiedBy == remoteBy { return false }
                if localWins(local.modifiedAt, local.modifiedBy, remoteAt, remoteBy) {
                    try requeueIfIdle(db, table: "setting", uuid: r.name, at: local.modifiedAt)
                    return false
                }
            }
            try Setting(key: r.name, value: r.string("value") ?? "", modifiedAt: remoteAt, modifiedBy: remoteBy).save(db)
            return true
        default:
            return false
        }
    }

    private static func upsert<T: SyncableRecord>(_ r: SyncRecord, in db: Database, make: () -> T,
                                                  fill: (inout T, Database) throws -> Void) throws -> Bool {
        let remoteAt = r.date("modifiedAt") ?? .distantPast
        let remoteBy = r.string("modifiedBy") ?? ""
        if var local: T = try db.fetchByUUID(uuid: r.name) {
            if local.deletedAt != nil { return false }                                  // R4: pending delete wins
            if local.modifiedAt == remoteAt && local.modifiedBy == remoteBy { return false }   // R9: already applied
            if localWins(local.modifiedAt, local.modifiedBy, remoteAt, remoteBy) {           // R3: ours goes back up
                try requeueIfIdle(db, table: T.databaseTableName, uuid: r.name, at: local.modifiedAt)
                return false
            }
            try fill(&local, db)
            try local.update(db)
            return true
        }
        var row = make()
        try fill(&row, db)
        try row.insert(db)
        return true
    }

    private static func requeueIfIdle(_ db: Database, table: String, uuid: String, at: Date) throws {
        let pending = try OutboxItem.filter(Column("tableName") == table && Column("uuid") == uuid).fetchCount(db)
        if pending == 0 { try db.logChange(table: table, uuid: uuid, op: .upsert, now: at) }
    }

    private static func resolve<T: SyncableRecord>(_: T.Type, uuid: String?, in db: Database) throws -> Int64? {
        guard let uuid, let row: T = try db.fetchByUUID(uuid: uuid), row.deletedAt == nil else { return nil }
        return row.id
    }

    // MARK: push

    static func type(forTable table: String) -> String {
        RecordMapper.types.first { RecordMapper.table(forType: $0) == table } ?? table
    }

    /// The current record for an outbox entry, or nil when the row is gone or tombstoned.
    static func record(forTable table: String, uuid: String, in db: Database) throws -> SyncRecord? {
        switch table {
        case "client":
            guard let c: Client = try db.fetchByUUID(uuid: uuid), c.deletedAt == nil else { return nil }
            return RecordMapper.record(client: c)
        case "project":
            guard let p: Project = try db.fetchByUUID(uuid: uuid), p.deletedAt == nil else { return nil }
            let client = try p.clientId.flatMap { try Client.fetchOne(db, key: $0) }
            return RecordMapper.record(project: p, clientUUID: client?.uuid)
        case "repo":
            guard let r: Repo = try db.fetchByUUID(uuid: uuid), r.deletedAt == nil else { return nil }
            let project = try r.projectId.flatMap { try Project.fetchOne(db, key: $0) }
            return RecordMapper.record(repo: r, projectUUID: project?.uuid)
        case "entry":
            guard let e: Entry = try db.fetchByUUID(uuid: uuid), e.deletedAt == nil else { return nil }
            let project = try e.projectId.flatMap { try Project.fetchOne(db, key: $0) }
            let repo = try e.repoId.flatMap { try Repo.fetchOne(db, key: $0) }
            return RecordMapper.record(entry: e, projectUUID: project?.uuid, repoUUID: repo?.uuid)
        case "setting":
            guard let s = try Setting.fetchOne(db, key: uuid) else { return nil }
            return RecordMapper.record(settingKey: s.key, value: s.value, modifiedAt: s.modifiedAt, modifiedBy: s.modifiedBy)
        default:
            return nil
        }
    }

    private static func clearOutbox(_ db: Database, table: String, uuid: String, upTo maxId: Int64) throws {
        try db.execute(sql: "DELETE FROM outbox WHERE tableName = ? AND uuid = ? AND id <= ?", arguments: [table, uuid, maxId])
    }

    public func push() async throws -> Int {
        let items = try db.pendingOutbox()
        guard let maxId = items.last?.id else { return 0 }
        var latest: [String: OutboxItem] = [:]
        var order: [String] = []
        for i in items {
            let key = "\(i.tableName)|\(i.uuid)"
            if latest[key] == nil { order.append(key) }
            latest[key] = i                                    // the last op for a row wins
        }
        var upserts: [SyncRecord] = []
        var deletes: [SyncRecordID] = []
        var stale: [OutboxItem] = []                           // upsert for a row that no longer exists
        try db.read { db in
            for key in order {
                let i = latest[key]!
                if i.op == SyncOp.delete.rawValue {
                    deletes.append(SyncRecordID(type: Self.type(forTable: i.tableName), name: i.uuid))
                } else if let r = try Self.record(forTable: i.tableName, uuid: i.uuid, in: db) {
                    upserts.append(r)
                } else {
                    stale.append(i)
                }
            }
        }
        var pushed = 0
        if !upserts.isEmpty {
            let outcomes = try await transport.save(upserts)
            try db.write { db in
                for r in upserts {
                    let table = RecordMapper.table(forType: r.type)!
                    switch outcomes[r.id] ?? .failed("no outcome") {
                    case .saved:
                        try Self.clearOutbox(db, table: table, uuid: r.name, upTo: maxId); pushed += 1
                    case .notFound:                                   // R4: deleted elsewhere meanwhile
                        if table == "setting" {
                            try db.execute(sql: "DELETE FROM setting WHERE key = ?", arguments: [r.name])
                        } else {
                            try db.execute(sql: "DELETE FROM \(table) WHERE uuid = ?", arguments: [r.name])
                        }
                        try Self.clearOutbox(db, table: table, uuid: r.name, upTo: maxId)
                    case .failed:
                        break                                         // stays queued, retried next cycle
                    }
                }
            }
        }
        if !deletes.isEmpty {
            try await transport.delete(deletes)
            try db.write { db in
                for id in deletes {
                    let table = RecordMapper.table(forType: id.type)!
                    try db.execute(sql: "DELETE FROM \(table) WHERE uuid = ?", arguments: [id.name])   // purge the tombstone
                    try Self.clearOutbox(db, table: table, uuid: id.name, upTo: maxId)
                }
            }
            pushed += deletes.count
        }
        if !stale.isEmpty {
            try db.write { db in
                for i in stale { try Self.clearOutbox(db, table: i.tableName, uuid: i.uuid, upTo: maxId) }
            }
        }
        return pushed
    }
}
```

```swift
extension Database {
    /// R7: after a merge at most one stint may run. The latest start keeps running; every other
    /// running entry ends at that start, or at its own start when that is later (zero length).
    /// Returns the number of stints ended. The changes are logged for push.
    public func resolveRunningStints(deviceId: String, now: Date) throws -> Int {
        let running = try Entry.filter(Column("endUTC") == nil && Column("deletedAt") == nil)
            .order(Column("startUTC").desc, Column("uuid").desc)
            .fetchAll(self)
        guard running.count > 1 else { return 0 }
        let keeper = running[0]
        for var e in running.dropFirst() {
            e.endUTC = max(e.startUTC, keeper.startUTC)
            try syncUpdate(&e, deviceId: deviceId, now: now)
        }
        return running.count - 1
    }
}
```

```swift
import Foundation
import GRDB

/// First day of the month `months - 1` months before `now`'s month (3 → current month plus two).
public func windowStart(now: Date, months: Int = 3, calendar: Calendar) -> Date {
    let comps = calendar.dateComponents([.year, .month], from: now)
    let first = calendar.date(from: comps)!
    return calendar.date(byAdding: .month, value: -(months - 1), to: first)!
}

extension AppDatabase {
    /// R14: drop finished entries that start before `cutoff`, locally only. Never logs to the outbox
    /// and skips rows that still have pending changes, so nothing is lost on the way to the server.
    @discardableResult
    public func pruneEntries(startingBefore cutoff: Date) throws -> Int {
        try write { db in
            let pending = Set(try String.fetchAll(db, sql: "SELECT uuid FROM outbox WHERE tableName = 'entry'"))
            let victims = try Entry.filter(Column("endUTC") != nil && Column("deletedAt") == nil && Column("startUTC") < cutoff)
                .fetchAll(db)
                .filter { !pending.contains($0.uuid) }
            for e in victims { _ = try e.delete(db) }
            return victims.count
        }
    }

    /// R15: raw hours of this month's finished entries plus the running stint's elapsed time.
    public func monthTotalHours(now: Date, calendar: Calendar) throws -> Double {
        let comps = calendar.dateComponents([.year, .month], from: now)
        let (start, end) = monthRange(year: comps.year!, month: comps.month!, calendar: calendar)
        let finished = try finishedEntries(from: start, to: end).reduce(0.0) { $0 + ($1.hours ?? 0) }
        let running = try runningEntry().map { max(0, now.timeIntervalSince($0.startUTC)) / 3600 } ?? 0
        return finished + running
    }
}
```

```swift
#if canImport(CloudKit)
import CloudKit
import Foundation

/// Production transport: one custom zone in the user's private database. Saves overwrite
/// (`.allKeys`); last-writer-wins is decided by the stamps in the records, not by the server.
public final class CloudKitTransport: SyncTransport, @unchecked Sendable {
    public static let zoneName = "stint"
    static let boolFields: Set<String> = ["archived"]
    let container: CKContainer
    let database: CKDatabase
    let zoneID: CKRecordZone.ID
    private var prepared = false

    public init(containerIdentifier: String = "iCloud.io.artnim.stint") {
        container = CKContainer(identifier: containerIdentifier)
        database = container.privateCloudDatabase
        zoneID = CKRecordZone.ID(zoneName: Self.zoneName, ownerName: CKCurrentUserDefaultName)
    }

    public func accountAvailable() async -> Bool {
        (try? await container.accountStatus()) == .available
    }

    /// Creates the zone and the change subscription once per process.
    public func prepare() async throws {
        guard !prepared else { return }
        _ = try await database.save(CKRecordZone(zoneID: zoneID))
        let sub = CKRecordZoneSubscription(zoneID: zoneID, subscriptionID: "stint-zone-changes")
        let info = CKSubscription.NotificationInfo()
        info.shouldSendContentAvailable = true
        sub.notificationInfo = info
        do { _ = try await database.save(sub) } catch let e as CKError where e.code == .serverRejectedRequest {
            // already exists with the same ID
        }
        prepared = true
    }

    // MARK: SyncTransport

    public func fetchChanges(since token: String?) async throws -> SyncChanges {
        let config = CKFetchRecordZoneChangesOperation.ZoneConfiguration()
        config.previousServerChangeToken = try token.map(Self.decodeToken)
        let op = CKFetchRecordZoneChangesOperation(recordZoneIDs: [zoneID], configurationsByRecordZoneID: [zoneID: config])
        var changed: [SyncRecord] = []
        var deleted: [SyncRecordID] = []
        var newToken: CKServerChangeToken?
        op.recordWasChangedBlock = { _, result in
            if case .success(let record) = result { changed.append(Self.syncRecord(from: record)) }
        }
        op.recordWithIDWasDeletedBlock = { id, type in deleted.append(SyncRecordID(type: type, name: id.recordName)) }
        op.recordZoneFetchResultBlock = { _, result in
            if case .success(let r) = result { newToken = r.serverChangeToken }
        }
        try await withCheckedThrowingContinuation { (cont: CheckedContinuation<Void, Error>) in
            op.fetchRecordZoneChangesResultBlock = { result in
                switch result {
                case .success: cont.resume()
                case .failure(let error): cont.resume(throwing: error)
                }
            }
            database.add(op)
        }
        return SyncChanges(changed: changed, deleted: deleted, token: try newToken.map(Self.encodeToken) ?? token)
    }

    public func save(_ records: [SyncRecord]) async throws -> [SyncRecordID: SyncSaveOutcome] {
        let ck = records.map { Self.ckRecord(from: $0, zoneID: zoneID) }
        let op = CKModifyRecordsOperation(recordsToSave: ck, recordIDsToDelete: nil)
        op.savePolicy = .allKeys
        op.isAtomic = false
        var out: [SyncRecordID: SyncSaveOutcome] = [:]
        op.perRecordSaveBlock = { id, result in
            let key = SyncRecordID(type: records.first { $0.name == id.recordName }?.type ?? "", name: id.recordName)
            switch result {
            case .success: out[key] = .saved
            case .failure(let error):
                if let e = error as? CKError, e.code == .unknownItem { out[key] = .notFound } else { out[key] = .failed(error.localizedDescription) }
            }
        }
        try await withCheckedThrowingContinuation { (cont: CheckedContinuation<Void, Error>) in
            op.modifyRecordsResultBlock = { result in
                switch result {
                case .success: cont.resume()
                case .failure(let error):
                    if let e = error as? CKError, e.code == .partialFailure { cont.resume() } else { cont.resume(throwing: error) }
                }
            }
            database.add(op)
        }
        return out
    }

    public func delete(_ ids: [SyncRecordID]) async throws {
        let op = CKModifyRecordsOperation(recordsToSave: nil, recordIDsToDelete: ids.map { CKRecord.ID(recordName: $0.name, zoneID: zoneID) })
        op.isAtomic = false
        try await withCheckedThrowingContinuation { (cont: CheckedContinuation<Void, Error>) in
            op.modifyRecordsResultBlock = { result in
                switch result {
                case .success: cont.resume()
                case .failure(let error):
                    if let e = error as? CKError, e.code == .partialFailure || e.code == .unknownItem { cont.resume() } else { cont.resume(throwing: error) }
                }
            }
            database.add(op)
        }
    }

    // MARK: mapping

    static func ckRecord(from r: SyncRecord, zoneID: CKRecordZone.ID) -> CKRecord {
        let record = CKRecord(recordType: r.type, recordID: CKRecord.ID(recordName: r.name, zoneID: zoneID))
        for (key, value) in r.fields {
            switch value {
            case .string(let s): record[key] = s as CKRecordValue
            case .int(let i): record[key] = i as CKRecordValue
            case .double(let d): record[key] = d as CKRecordValue
            case .bool(let b): record[key] = (b ? Int64(1) : Int64(0)) as CKRecordValue
            case .date(let d): record[key] = d as CKRecordValue
            case .strings(let l): record[key] = l as CKRecordValue
            case .null: record[key] = nil
            }
        }
        return record
    }

    static func syncRecord(from record: CKRecord) -> SyncRecord {
        var fields: [String: SyncValue] = [:]
        for key in record.allKeys() {
            switch record[key] {
            case let s as String: fields[key] = .string(s)
            case let d as Date: fields[key] = .date(d)
            case let l as [String]: fields[key] = .strings(l)
            case let n as NSNumber:
                if boolFields.contains(key) { fields[key] = .bool(n.boolValue) }
                else if CFNumberIsFloatType(n) { fields[key] = .double(n.doubleValue) }
                else { fields[key] = .int(n.int64Value) }
            default: break
            }
        }
        return SyncRecord(type: record.recordType, name: record.recordID.recordName, fields: fields)
    }

    static func encodeToken(_ token: CKServerChangeToken) throws -> String {
        try NSKeyedArchiver.archivedData(withRootObject: token, requiringSecureCoding: true).base64EncodedString()
    }

    static func decodeToken(_ s: String) throws -> CKServerChangeToken {
        guard let data = Data(base64Encoded: s),
              let token = try NSKeyedUnarchiver.unarchivedObject(ofClass: CKServerChangeToken.self, from: data) else {
            throw CKError(.internalError)
        }
        return token
    }
}
#endif
```

```swift
    static weak var shared: AppState?   // read only from @MainActor tasks

    var syncStatus = "Sync: not started"
    private var transport: CloudKitTransport?
    private var engine: SyncEngine?
    private var debouncedSync: Task<Void, Never>?
    private var periodicSync: Timer?

    func startSync() {
        Self.shared = self
        let transport = CloudKitTransport()
        self.transport = transport
        engine = SyncEngine(database: db, transport: transport)
        periodicSync = Timer.scheduledTimer(withTimeInterval: 300, repeats: true) { [weak self] _ in
            Task { @MainActor in await self?.syncNow(reason: "periodic") }
        }
        Task { await syncNow(reason: "launch") }
    }

    func syncNow(reason: String) async {
        guard let transport, let engine else { return }
        guard await transport.accountAvailable() else { syncStatus = "Sync off: not signed in to iCloud"; return }
        do {
            try await transport.prepare()
            let s = try await engine.sync()
            refresh()
            let stamp = Date().formatted(date: .omitted, time: .shortened)
            syncStatus = "Synced \(stamp): \(s.pushed) up, \(s.pulled) down" + (s.deleted > 0 ? ", \(s.deleted) deleted" : "")
        } catch {
            syncStatus = "Sync problem: \(error.localizedDescription)"
        }
    }

    /// Called after every local write: sync two seconds after the last one.
    func scheduleSync() {
        debouncedSync?.cancel()
        debouncedSync = Task { [weak self] in
            try? await Task.sleep(for: .seconds(2))
            guard !Task.isCancelled else { return }
            await self?.syncNow(reason: "local change")
        }
    }
```

```swift
    private static func query(_ account: String, service: String = service, synchronizable: Bool = false) -> [String: Any] {
        var q: [String: Any] = [kSecClass as String: kSecClassGenericPassword,
                                kSecAttrService as String: service,
                                kSecAttrAccount as String: account]
        if synchronizable {
            q[kSecAttrSynchronizable as String] = true
            #if os(macOS)
            q[kSecUseDataProtectionKeychain as String] = true   // synchronizable items live in the data-protection keychain
            #endif
        }
        return q
    }

    static func read(_ account: String) -> String? {
        if let value = read(account, service: service, synchronizable: true) { return value }
        // first launch after enabling sync, or after the rename: adopt the local item
        for (svc, sync) in [(service, false), (legacyService, false)] {
            if let legacy = read(account, service: svc, synchronizable: sync) {
                try? write(account, legacy)
                SecItemDelete(query(account, service: svc, synchronizable: sync) as CFDictionary)
                return legacy
            }
        }
        return nil
    }

    private static func read(_ account: String, service: String, synchronizable: Bool) -> String? {
        var q = query(account, service: service, synchronizable: synchronizable)
        q[kSecReturnData as String] = true
        q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess, let data = out as? Data else { return nil }
        return String(data: data, encoding: .utf8)
    }

    static func write(_ account: String, _ value: String) throws {
        delete(account)
        var q = query(account, synchronizable: true)
        q[kSecValueData as String] = Data(value.utf8)
        let status = SecItemAdd(q as CFDictionary, nil)
        guard status == errSecSuccess else { throw KeychainError(status: status) }
    }

    static func delete(_ account: String) {
        SecItemDelete(query(account, synchronizable: true) as CFDictionary)
    }
```

```swift
import Foundation

public struct GitHubAccountCredential: Sendable {
    public var label: String
    public var token: String
    public init(label: String, token: String) { self.label = label; self.token = token }
}

public struct AccountSyncOutcome: Equatable, Sendable {
    public var rejectedLabels: [String]
    public var failed: Int
    public var applied: Bool
}

/// The issue sync shared by both apps: assigned issues per account, every open and recently
/// closed issue of each tracked repo, merged and applied; closes missing issues only when
/// everything succeeded.
public enum AccountSync {
    public static func run(accounts: [GitHubAccountCredential], db: AppDatabase, closedSince: Date,
                           makeClient: (String) -> GitHubClient = { GitHubClient(token: $0) }) async -> AccountSyncOutcome {
        var assigned: [GitHubIssue] = []
        var rejected: [String] = []
        var failed = 0
        for account in accounts {
            do {
                let client = makeClient(account.token)
                assigned += try await client.assignedIssues()
                assigned += try await client.assignedIssues(state: "closed", since: closedSince)
            } catch GitHubError.unauthorized {
                rejected.append(account.label); failed += 1
            } catch {
                failed += 1
            }
        }
        let usable = accounts.filter { !rejected.contains($0.label) }
        var listed: [GitHubIssue] = []
        for repo in (try? db.allRepos()) ?? [] {
            var fetched = false
            for account in usable {
                do {
                    let client = makeClient(account.token)
                    listed += try await client.repoIssues(owner: repo.owner, name: repo.name)
                    listed += try await client.repoIssues(owner: repo.owner, name: repo.name, state: "closed", since: closedSince, maxPages: 2)
                    fetched = true
                    break
                } catch GitHubError.http(let code) where code == 403 || code == 404 {
                    continue
                } catch {
                    break
                }
            }
            if !fetched { failed += 1 }
        }
        let merged = IssueSync.merge(assigned: assigned, repoIssues: listed)
        var applied = false
        if !merged.isEmpty || failed == 0 {
            applied = (try? IssueSync.apply(merged, to: db, closeMissing: failed == 0)) != nil
        }
        return AccountSyncOutcome(rejectedLabels: rejected, failed: failed, applied: applied)
    }
}
```

```swift
import CloudKit
import Foundation
import Observation
import TimeCore

@Observable @MainActor
final class MobileState {
    static weak var shared: MobileState?   // read only from @MainActor tasks
    let db: AppDatabase
    var running: Entry?
    var recents: [RecentItem] = []
    var projects: [Project] = []
    var repos: [Repo] = []
    var issueRows: [IssueRow] = []
    var allIssueRows: [IssueRow] = []
    var monthTotal: Double = 0
    var now = Date()
    var lastError: String?
    var githubError: String?
    var syncStatus = "Sync: not started"
    private let transport = CloudKitTransport()
    private let engine: SyncEngine
    private var debounced: Task<Void, Never>?

    static var databaseURL: URL {
        FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0].appending(path: "Stint/stint.sqlite")
    }

    init() {
        db = try! AppDatabase.open(at: Self.databaseURL)      // the phone has no alert path; a failure here is a programming error
        engine = SyncEngine(database: db, transport: transport)
        Self.shared = self
        refresh()
        Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.now = Date(); self?.monthTotal = (try? self?.db.monthTotalHours(now: Date(), calendar: .current)) ?? 0 }
        }
    }

    func refresh() {
        do {
            running = try db.runningEntry()
            recents = try db.recents(limit: 10)
            projects = try db.allProjects()
            repos = try db.allRepos()
            issueRows = try db.openIssueRows()
            allIssueRows = try db.searchIssueRows(closedSince: Date().addingTimeInterval(-30 * 86400))
            monthTotal = try db.monthTotalHours(now: Date(), calendar: .current)
        } catch { lastError = "\(error)" }
    }

    var userName: String {
        get { (try? db.setting("userName")) ?? "" }
        set { try? db.setSetting("userName", newValue); scheduleSync() }
    }

    func projectName(_ id: Int64?) -> String { projects.first { $0.id == id }?.name ?? "" }

    func elapsed(_ e: Entry) -> String {
        let s = Int(max(0, now.timeIntervalSince(e.startUTC)))
        return String(format: "%d:%02d:%02d", s / 3600, (s % 3600) / 60, s % 60)
    }

    func perform(_ block: () throws -> Void) {
        do { try block(); lastError = nil } catch { lastError = "\(error)" }
        refresh()
        scheduleSync()
    }

    func start(_ item: RecentItem) {
        perform { try db.start(description: item.description, projectId: item.projectId, repoId: item.repoId,
                               issueNumber: item.issueNumber, issueTitle: item.issueTitle) }
    }
    func startIssue(_ row: IssueRow) {
        perform { try db.start(description: "#\(row.issue.number): \(row.issue.title)", projectId: row.repo.projectId,
                               repoId: row.repo.id, issueNumber: row.issue.number, issueTitle: row.issue.title) }
    }
    func startNew(description: String, projectId: Int64?) { perform { try db.start(description: description, projectId: projectId) } }
    func stop() { perform { try db.stopRunning() } }
    func update(_ entry: Entry) -> Bool {
        if let end = entry.endUTC, end <= entry.startUTC { lastError = "End must be after start."; return false }
        perform { try db.update(entry) }
        return lastError == nil
    }
    func delete(_ entry: Entry) { perform { try db.delete(entry) } }
    func assignRepo(_ repoId: Int64, to projectId: Int64?) { perform { try db.assignRepo(repoId, toProject: projectId) } }
    func createProject(named name: String) -> Int64? { var p = Project(clientId: nil, name: name); perform { try db.insert(&p) }; return p.id }
    func windowEntries() -> [Entry] {
        (try? db.entries(from: windowStart(now: Date(), calendar: .current), to: Date().addingTimeInterval(86400))) ?? []
    }

    // MARK: sync

    func scheduleSync() {
        debounced?.cancel()
        debounced = Task { [weak self] in
            try? await Task.sleep(for: .seconds(2))
            guard !Task.isCancelled else { return }
            await self?.syncNow()
        }
    }

    func syncNow() async {
        guard await transport.accountAvailable() else { syncStatus = "Sync off: not signed in to iCloud"; return }
        do {
            try await transport.prepare()
            let s = try await engine.sync()
            try db.pruneEntries(startingBefore: windowStart(now: Date(), calendar: .current))   // R14
            refresh()
            syncStatus = "Synced \(Date().formatted(date: .omitted, time: .shortened)): \(s.pushed) up, \(s.pulled) down"
        } catch {
            syncStatus = "Sync problem: \(error.localizedDescription)"
        }
    }

    func syncIssues() async {
        let accounts = KeychainStore.githubAccounts().map { GitHubAccountCredential(label: $0.label, token: $0.token) }
        guard !accounts.isEmpty else { githubError = "No GitHub token. Add one in Settings."; return }
        let outcome = await AccountSync.run(accounts: accounts, db: db, closedSince: Date().addingTimeInterval(-30 * 86400))
        if outcome.applied { refresh() }
        githubError = outcome.rejectedLabels.isEmpty ? nil : "GitHub rejected the token for \(outcome.rejectedLabels.joined(separator: ", "))."
    }
}
```
